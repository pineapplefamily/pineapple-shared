# pineapple-shared
shared repo for admin and platform 


## design-tokens.css

Canonical design tokens (colors, fonts, radius, light + dark) for the platform and admin console. Both `pf-primary/src/index.css` and `pineapple-admin/src/index.css` must mirror these values. Fonts load from Adobe Fonts kit `jwu6ygh`. Kept in sync manually, like `profileFields.ts`.
